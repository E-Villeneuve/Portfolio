# My portfolio

A one-page portfolio in plain HTML, CSS and JavaScript. This was designed to make adding new projects and assets as easy as possible for myself.
```
index.html        page structure: hero, About, Contact
css/style.css     all styling
js/data.js        skills and projects 
js/main.js        builds Skills and Projects from data.js, the hero terminal, the skill filter
assets/           screenshots and other additional files
```

## Preview locally

```bash
python -m http.server 8000
```


The `.nojekyll` file tells GitHub Pages to serve the files as they are.
